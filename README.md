## О проекте

**Что делает.** Бот принимает сообщения в личном чате Telegram и сам понимает,
что нужно сделать: создать, показать, завершить, перенести или удалить задачу.
Он распознаёт относительные даты («завтра в 18:00», «на пятницу») и заранее
присылает напоминания о сроке. Языковая модель вызывает функции (tool calling),
а непосредственную работу с базой данных выполняет код, а не модель.

**Пример диалога:**
- «Добавь задачу сделать лабораторную завтра в 18:00»
- «Что у меня завтра?»
- «Я закончил лабораторную»
- «Перенеси лабораторную на пятницу в 15:00»

**Актуальность.** Обычные планировщики требуют заполнять формы и выбирать
даты вручную, поэтому задачи часто не записываются вовсе. Здесь достаточно
написать фразу как в мессенджере, а напоминания за несколько суток, часов и
минут до срока помогают не пропускать дедлайны. Проект также показывает,
как безопасно подключить LLM к реальному приложению: модель только выбирает
действие, а проверку данных и права доступа обеспечивает backend.

## Стек

Python 3.12, aiogram 3, PostgreSQL 16, SQLAlchemy 2 (async), Groq API
(`openai/gpt-oss-20b`), APScheduler, Docker Compose.

## Запуск

1. Получите токен бота у @BotFather и API-ключ в [Groq Console](https://console.groq.com/keys).
2. Создайте настройки и впишите в `.env` значения `TELEGRAM_BOT_TOKEN` и `GROQ_API_KEY`:
```bash
   cp .env.example .env
```
3. Запустите проект и отправьте боту `/start`:
```bash
   docker compose up --build
```

## Структура

```text
hse/
├── config.py        # настройки и переменные окружения
├── database.py      # подключение к БД, модели User и Task
├── repository.py    # SQL-запросы
├── task_service.py  # бизнес-логика и валидация
├── llm_service.py   # Groq и вызов инструментов (tools)
├── bot.py           # обработчики Telegram
├── main.py          # запуск приложения и напоминания
├── Dockerfile
├── docker-compose.yml
└── .env.example
```

Схема работы: `Telegram → bot → llm_service → Groq → task_service → repository → PostgreSQL`.
